---
description: How to start and run the PipCleaner application
---
Follow these steps to run the PipCleaner application in your terminal:

1. Open a workspace terminal inside the `c:\Users\Can\pip tool` directory.
2. Execute the following command to boot up the python backend server:
// turbo
```bash
python server.py
```
3. The program will automatically trace distributions, build package size caches, and launch the dashboard in your default browser at `http://localhost:49150`.
4. To shut down the server, press `Ctrl+C` inside the terminal window.
